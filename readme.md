# Tic Tac Toe Game

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay
- Winner detection
- Reset game button
- New game button
- Simple and clean UI

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository
2. Open `index.html` in your browser

## Project Structure
- `index.html`
- `style.css`
- `app.js`

## Learning Outcome
This project helped practice:
- DOM manipulation
- Event handling
- Game logic
- UI updates with JavaScript
